  --name jenkins \

docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword

🐳 Docker Swarm Multi-Node Cluster (20 ពិន្ទុ)

ការបង្កើត Cluster 1 Manager + 2 Workers, Replicas, Rolling Update & Stack Deploy

១. Command បង្កើត Swarm Cluster

# 1. លើ Manager Node (ផ្តួចផ្តើម Swarm)
docker swarm init --advertise-addr <MANAGER_IP>

# 2. យក Join-Token ទៅ Run លើ Worker Node ទី ១ និង ទី ២
docker swarm join --token <WORKER_TOKEN> <MANAGER_IP>:2377

# 3. ពិនិត្យមើល Nodes ទាំងអស់លើ Manager (ត្រូវឃើញ Ready ទាំង 3)
docker node ls

២. File docker-stack.yml (Production Stack)

version: '3.8'

services:
  web:
    image: phor2026/jenkins-demo-app:latest
    deploy:
      replicas: 3
      restart_policy:
        condition: on-failure
      update_config:
        parallelism: 1
        delay: 5s
        order: start-first
    networks:
      - app-net

  loadbalancer:
    image: nginx:alpine
    ports:
      - "9099:80"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    deploy:
      placement:
        constraints: [node.role == manager]
    networks:
      - app-net

networks:
  app-net:
    driver: overlay

Traffic Management

⚖️ Load Balancing Architecture (Layer 4 vs Layer 7)

ការប្រៀបធៀប និង Configuration នៃ Nginx, HAProxy និង Traefik

Layer 4 — Transport

TCP / UDP (Fast Routing)

  • មើលឃើញត្រឹម IP Address និង Port
  • ល្បឿនលឿនបំផុត ស៊ី CPU តិចតួច
  • មិនអាច Route តាម URL Path ឬ Hostname បានទេ
  • ឧទាហរណ៍: HAProxy (tcp mode), AWS NLB
Layer 7 — Application

HTTP / HTTPS (Smart Routing)

  • មើលឃើញ Headers, Cookies, URL Paths, Hostname
  • អាចធ្វើ TLS/SSL Termination និង Health Check បាន
  • Route ទៅ Microservices ផ្សេងៗគ្នាតាម Path
  • ឧទាហរណ៍: Nginx, Traefik, HAProxy (http), AWS ALB

Nginx Reverse Proxy Config (nginx.conf)

events {}
http {
    upstream backend_servers {
        least_conn; # Algorithm: round-robin, least_conn, ip_hash
        server web:80;
    }

    server {
        listen 80;
        location / {
            proxy_pass http://backend_servers;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
        }
    }
}

🏗️ Terraform AWS EC2 & Security Group (30 ពិន្ទុ)

ការបង្កើត Infrastructure ស្វ័យប្រវត្តិតាមកូដ .tf ដោយមិនបាច់ចុចដៃលើ AWS Console

main.tf (VPC, EC2 & Security Group)

terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}

provider "aws" {
  region = "ap-southeast-1" # Singapore Region
}

# 1. Security Group
resource "aws_security_group" "web_sg" {
  name        = "jenkins-cicd-sg"
  description = "Allow SSH, HTTP, and App ports"

  ingress {
    description = "SSH"
    from_port   = 22
    to_port     = 22
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  ingress {
    description = "App Port"
    from_port   = 9099
    to_port     = 9099
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }

  tags = {
    Name = "jenkins-cicd-sg"
  }
}

# 2. EC2 Instance
resource "aws_instance" "web_server" {
  ami           = "ami-0df7a207adb9748c7" # Ubuntu 22.04 LTS
  instance_type = "t2.micro"
  key_name      = "my-ec2-key"
  security_groups = [aws_security_group.web_sg.name]

  tags = {
    Name        = "Jenkins-CI-CD-Server"
    Environment = "Production"
  }
}

output "public_ip" {
  value = aws_instance.web_server.public_ip
}

Cheat Sheet

🛠️ កម្រងបញ្ហាទូទៅ និងដំណោះស្រាយរហ័ស (Troubleshooting)

1. fatal: not in a git directory

មូលហេតុ: Jenkins បើកមុខងារ "Lightweight checkout" ធ្វើឱ្យ Git មិនទាន់ Clone repository ពេញលេញ។

➔ ចូល Job Configure ➔ Pipeline ➔ ដោះធីក (Uncheck) "Lightweight checkout" ➔ Save

2. Could not find credentials entry with ID 'docker-hub-credentials'

មូលហេតុ: មិនទាន់បានបង្កើត Credential ID នេះក្នុង Jenkins ឬវាយឈ្មោះ ID ខុស។

➔ ចូល Manage Jenkins ➔ Credentials ➔ Add Credentials (Kind: Username with password, ID: docker-hub-credentials)

3. EC2 Site can't be reached (Connection Timed Out)

មូលហេតុ: AWS Security Group មិនទាន់បើក Inbound Rule លើ Port 9099។

➔ ចូល AWS Console ➔ EC2 ➔ Security Groups ➔ Edit Inbound Rules ➔ Add Port 9099 (Source: 0.0.0.0/0)
